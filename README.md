# 古玩寄卖行（claude-qd-1202）

Spring Boot 3.3 + Vue3(Element Plus) 全栈种子仓，题材为**古玩字画寄卖店铺**。可 `docker compose up` 直接跑起，页面可打开、接口有数据。

## 技术栈
- 后端：Spring Boot 3.3 + Spring Data JPA + MySQL，统一 `ApiResponse.success` 返回 `{ok:true,data}`，业务错误抛 `BizException` 映射 400 中文。
- 前端：Vue3 + Element Plus，`App.vue` 驱动 `router` + `<component :is>`（不改 `main.js`），`api/index.js` 用 `call()` 校验 `body.ok`。

## 主色与导航
- 主色：赭红 `#8B3A3A`（见 `frontend/src/styles/main.css`）。
- 导航：顶部图标条（`App.vue`）。
- 操作范式：**分组折叠**——各模块按品类/状态分组，展开看明细。

## 端口（.env，勿改）
- 前端 8322 / 后端 8422 / MySQL 3622 / Redis 6622 / 库名 `antique_resale`。

## 四大业务模块与关系面
1. **寄卖品台账**（`/items`）：登记瓷器/字画/玉器/杂项，含品类、名称、年代、委托方、估价、状态。
   - 关系面：①品类必须在 瓷器/字画/玉器/杂项；②估价必填且 >0；③已售出不可改价；④已撤回不可再上架。
2. **估价记录**（`/appraisals`）：每件寄卖品可有多条估价，含评估师、金额、日期、状态。
   - 关系面：①同一物品多次估价留痕；②估价金额必须 >0；③状态 待评/已评，仅待评可完成。
3. **寄卖状态流转**（`/flow`）：状态机，已售出锁价、已撤回不可再上架，每次合法跳转留痕。
   - 关系面：①合法跳转（在售/已预订互转、走向已售/已撤回）；②已售出、已撤回为终态；③非法跳转（如已售出→在售）拦截抛中文。
4. **买家与结算**（`/settlement`）：买家信息 + 成交记录（成交价、佣金比例、佣金金额、结算状态）。
   - 关系面：①佣金=成交价×比例自动计算；②成交价不得低于估价红线（拦截低于估价）；③仅「已售出」可结算；④结算状态 未结算/已结算。

## 自检
- `backend/.../entity/` 下无字段 Java 初值；两处 `schema.sql`（`backend/src/main/resources/` 与 `mysql/`）内容一致。
- 种子含异常态：`GM-1003` 已售出（用于改价拦截）、`GM-1004` 已撤回（再上架拦截）、`appraisal` 一条金额 0（估价>0 拦截）、`deal` 含低于红线与未售出成交（红线/已售校验）。
